# Gameplay map terrain graphics

This directory contains the **actual map-screen terrain/property graphics**, distinct from the larger Bank $17 battle-place artwork under `../battle_places/`.

## Build asset

- `terrain_tiles.png` — 96 8x8 Game Boy tiles, 16 tiles per row (128x48), loaded from Bank $01:$5268-$5867 into VRAM bank 0 at $9000. This is the active build input.
- `terrain_tiles.orig.png` — retail Japanese reference extraction from the same verified ROM range. Keep this as the baseline if `terrain_tiles.png` is edited later.
- `terrain_tiles.2bpp` — generated by `rgbgfx` during the build and normally excluded from packaged source archives.

The 96 tiles are assembled into 16x16 map cells by the 52-entry `MapMetatileDefinitions` table at ROM0:$1C6C. Each metatile stores four `(tile ID, CGB BG attribute)` pairs in top-left, top-right, bottom-left, bottom-right order.

## Derived metatile compositions

`metatiles/` contains 16x16 neutral compositions derived from the retail tile sheet and metatile table. They are organization/reference files, not independent build inputs. CGB palette selection remains in the source metatile attributes, so side-specific property compositions can share the same shapes while using different in-game palettes.

Natural terrain IDs are ROM-backed through `TerrainNameIndexByMapTile` and `Terrain_Name_Strings`:

- `$20` plain
- `$21` road
- `$22-$23` bridge variants
- `$24` mountain
- `$25` wood
- `$26` wasteland
- `$27` desert
- `$28` river
- `$29` sea
- `$2A` shoal
- `$2B-$31` additional sea metatile variants that resolve to the SEA display name

Property metatiles occupy `$01-$1F`: `$01-$0B` O.STAR/side-0, `$0C-$16` W.MOON/side-1, and `$17-$1F` neutral variants. The exact side names are kept out of the filenames so the graphics hierarchy remains useful even where higher-level faction terminology changes.

Run `tools/extract_map_terrain.py baserom.gbc` to refresh the retail reference and derived compositions. The script does **not** overwrite an existing active `terrain_tiles.png`.

## Neutral composition / palette model

`source_tiles/terrain_tiles.png` is the exact 96-tile ROM-order build source. `terrain_tiles.png` is a neutral atlas of the 52 recognizable 16x16 metatiles, and `metatiles/**/*.png` stores the individual neutral compositions. CGB palette numbers remain in the metatile attribute source and `map_screen.pal`; no palette-specific PNG variants or preview atlas are retained.
