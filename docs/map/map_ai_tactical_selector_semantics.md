# the project: final Bank $0D tactical selector semantics

the project performs the final focused semantic split of the previously byte-owned Bank `$0D:$6325-$6617` continuation. The exact 755-byte retail range is unchanged (SHA-1 `7883df41e40c6fc736b23eac8270ec01c8b1cb7e`), but it is no longer represented as one opaque block.

The `$6325` wrapper supplies the zero-terminated list `{ Bomber, 0 }` to the generic planner runner at `$6472`. The resulting `$632E` planner searches candidate coordinates, stages movement when the selected target cannot be used immediately, and reaches the already-source-owned `MapAI_DispatchAreaAttackAtCoordinates` path. Two target searches are now separated: `$638F` scans the bounded map rectangle and `$63E5` scans the 100 analysis records as a fallback. Both use `$6443`, which counts cells classified as `MAP_TILE_PHASE_CLASS_OPPOSING_PROPERTY` across the center plus its six hex neighbors.

`$6472` is a generic ordered-unit planner runner. It copies the caller's zero-terminated unit-type order to WRAM, scans the active 50-unit pool, rejects ineligible live records, filters the surviving type through that order, loads the selected unit tactical context, and dispatches by unit type. The pointer table at `$64C4` has exactly 52 entries, covering real UnitData types 0-51 and excluding `DUMMY`: Infantry/Missile Infantry/Mercenary Infantry select direct-attack family 0; Construction Truck selects direct-attack family 1; Bomber/Mercenary Bomber select the Bomber area planner; all other real types point to a no-op planner. The current Bomber wrapper itself orders only the standard Bomber type.

The `$6563+` tail is now separated into selected-unit context helpers. `$6574` copies the selected live unit to shared scratch, builds its weapon summary, stages its coordinates and clears the shared action workspace. `$65A9` lazily initializes the associated map/path context. The final position/carried-state helpers remain conservatively named where the precise presentation-side purpose is not yet independently proven.

With this split, Bank `$0D` tactical AI is sufficiently source-owned and semantically organized that further work here should be opportunistic cleanup rather than the project's main work sequence. The next large target should move to the Mobile/network overlay, then briefing/text-pointer and battle-graphics decomposition.
